# Diabetes Dataset - ydata-profiling

This repository contains a Jupyter Notebook for exploratory data analysis (EDA) of a diabetes dataset using the `ydata-profiling` library.

## Project Overview

The main goal of this project is to analyze a diabetes dataset and generate a comprehensive profiling report that highlights:

- dataset overview,
- variable types,
- missing values,
- statistical summaries,
- correlations,
- distributions,
- data quality insights.

The project is implemented in Python and uses Jupyter Notebook for interactive analysis.

## Dataset

The project analyzes a diabetes dataset, commonly used for machine learning and statistical analysis tasks.

The notebook includes steps to:
- load the dataset,
- inspect the data,
- clean and prepare it if needed,
- summarize key statistics,
- visualize relationships between variables,
- generate a `ydata-profiling` report.

## Tools and Libraries

The analysis uses the following technologies:

- Python
- Jupyter Notebook
- pandas
- numpy
- matplotlib
- seaborn
- ydata-profiling

## Requirements

Make sure Python 3 is installed, then install the required dependencies:

```bash
pip install jupyter pandas numpy matplotlib seaborn ydata-profiling
```

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/ghada-59/Diabetes-dataset-ydata-profiling.git
```

2. Open the project folder:

```bash
cd Diabetes-dataset-ydata-profiling
```

3. Launch Jupyter Notebook:

```bash
jupyter notebook
```

4. Open the file:

```bash
Diabetes_data_analyzing.ipynb
```

5. Run the cells in order to execute the analysis and generate the report.

## What the Notebook Includes

The notebook covers:

- import of libraries,
- loading the dataset,
- dataset inspection,
- overview of variables,
- missing data analysis,
- descriptive statistics,
- correlation analysis,
- graphical visualizations,
- generation of the automated profiling report.

## Report Generated with ydata-profiling

`ydata-profiling` generates an HTML report that provides a clear overview of the dataset, including:

- variable summaries,
- error and missing data detection,
- distribution plots,
- correlation matrix,
- data quality indicators,
- useful insights for further analysis.

This is especially useful for exploratory analysis before building a machine learning model.

## Project Goals

This project is useful for:

- understanding the data before modeling,
- detecting anomalies and missing data,
- identifying important relationships between variables,
- preparing a dataset for machine learning tasks.
